# Codex Replica Toolkit

Универсальные навыки Codex для исследования сервисов и создания самостоятельной реализации. 11 направлений и 6 локальных Python-утилит. Не требуется подключение к аккаунту автора или его проектам.

Основано на MIT-проекте [replica-skill](https://github.com/Jakeschincariol/replica-skill/tree/77c9436fb3d18c3d58169efb8caf4fe906b0dc51), проверенный commit `77c9436fb3d18c3d58169efb8caf4fe906b0dc51`. Инструкции переписаны для Codex, утилиты усилены. Независимая адаптация, неофициальное продолжение исходного проекта.

## Быстрый старт для друга

Требуются Git, Codex и Python 3 (проверено на 3.12). Утилиты рассчитаны на Linux, macOS или WSL; сторонние Python-пакеты не нужны.

Клонируй этот репозиторий:

```sh
git clone https://github.com/reeboksport785-cyber/Skills-coping-.git codex-replica-toolkit
cd codex-replica-toolkit
```

Для установки через помощника можно открыть новый чат Codex и написать:

> Установи все 11 навыков из https://github.com/reeboksport785-cyber/Skills-coping- (каталог skills/) в мою пользовательскую папку ~/.agents/skills. Сначала прочитай README и сведения о безопасности, запусти тесты. Существующие версии сначала сравни, затем сообщи результат установки и доступные имена навыков.

Установка выполняется один раз на каждом компьютере. После неё навыки доступны в новых чатах без повторной пересылки файлов. Ссылка на репозиторий сама по себе не устанавливает навыки и не запускает код.

Сначала прочитай [проверку безопасности](docs/security-review.ru.md) и инструкции нужного навыка. Здесь нет команды загрузки и немедленного исполнения удалённого установщика.

Проверь инструменты:

```sh
python3 -I -B -m unittest discover -s skills/codex-replica-diff/scripts/tests -v
```

Установи все 11 папок из `skills/` в каталог пользовательских навыков `~/.agents/skills/`. Копируй папки целиком, включая `scripts/`, `assets/`, `references/` и `LICENSE`. Если папка уже существует, сначала сравни версии; не объединяй их вслепую.

Пример для новой установки в Linux/macOS/WSL — запускать из корня этого репозитория:

```sh
(
  set -eu
  replica_skills_target="$HOME/.agents/skills"
  mkdir -p "$replica_skills_target"
  for replica_skill_source in skills/codex-replica-*; do
    replica_skill_name="${replica_skill_source##*/}"
    if [ -e "$replica_skills_target/$replica_skill_name" ] || [ -L "$replica_skills_target/$replica_skill_name" ]; then
      echo "Уже существует: $replica_skill_name. Сначала сравни версии."
      exit 1
    fi
  done
  cp -R skills/codex-replica-* "$replica_skills_target/"
)
```

Для одного проекта можно скопировать те же папки в `<project>/.agents/skills/`. Не устанавливай одинаковые имена одновременно в обе области без необходимости. Codex обнаруживает навыки автоматически; если они не появились, перезапусти Codex. Источник: [официальная инструкция OpenAI](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills), проверено 2026-10-23.

Установка копирует данные и инструкции. Сетевые обращения, браузер, платные сервисы и публикация зависят от доступных инструментов и отдельной задачи пользователя.

## Что входит

| Навык | Когда использовать |
| --- | --- |
| `$codex-replica-recon` | Разобрать URL/экраны и составить карту функций/сценариев |
| `$codex-replica-architect` | Спроектировать архитектуру, данные и API |
| `$codex-replica-design` | Воссоздать дизайн-систему, компоненты и адаптивность |
| `$codex-replica-build` | Реализовать экраны и пользовательские сценарии |
| `$codex-replica-backend` | Добавить реальные данные, права и интеграции |
| `$codex-replica-test` | Проверить реализацию и воспроизвести дефекты |
| `$codex-replica-diff` | Сравнить функции/изображения и найти пробелы |
| `$codex-replica-entrepreneur` | Разобрать настоящие отзывы и выбрать улучшения |
| `$codex-replica-brand` | Создать свою идентичность и найти остатки чужого брендинга |
| `$codex-replica-launch` | Подготовить лендинг, цены и описания для запуска |
| `$codex-replica-deploy` | Проверить готовность и выполнить запрошенный выпуск |

Обычный запрос в Codex: «Разбери этот сервис по ссылке и создай нашу реализацию». Явный запуск: «Используй `$codex-replica-recon` для этого URL». Для проверки: «Используй `$codex-replica-diff` и покажи, чего не хватает».

Недоступный серверный код, частные данные и пользовательская база не извлекаются из URL. Навыки помогают воссоздать доступные экраны, функции и поведение; неизвестные части отмечаются отдельно и проектируются для нашей реализации.

## Локальные утилиты

| Файл | Задача |
| --- | --- |
| `skills/codex-replica-design/scripts/contrast.py` | Контраст пар цветов |
| `skills/codex-replica-diff/scripts/imgdiff.py` | Сравнение PNG в режиме layout/pixel |
| `skills/codex-replica-diff/scripts/parity.py` | Оценка матрицы функций |
| `skills/codex-replica-entrepreneur/scripts/reviews.py` | Эвристическая классификация предоставленных отзывов |
| `skills/codex-replica-brand/scripts/sweep.py` | Поиск нежелательных имён, доменов и цветов |
| `skills/codex-replica-launch/scripts/listing.py` | Структурная проверка описаний магазинов |

Запускай через `python3 -I -B <path> --help`. Скрипты не выполняют сетевых запросов и не устанавливают пакеты. Новые результаты не перезаписывают существующие файлы; неподдерживаемые данные и небезопасные ссылки отклоняются. Оценки — вспомогательные метрики, а не гарантия идентичности, безопасности приложения или допуска в магазин.

## Поддержка и обновления

Изменения проверяются комплектом из 74 тестов. Утилиты и шаблоны находятся в самих навыках; каталоги следует передавать комплектом. Автоматического обновления исходного проекта нет. Перед обновлением сравни commit/diff и повтори проверки. Удаление установленного набора — удаление именно этих 11 каталогов из выбранной области; это не изменяет созданные с их помощью проекты.
