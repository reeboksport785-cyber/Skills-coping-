# Одна ссылка для работы с набором

Отправь эту страницу в текущий чат Codex/ChatGPT Work вместе с задачей. Помощник прочитает нужные инструкции и применит их к доступному проекту. Для постоянного появления навыков в списке нужна отдельная установка в используемой среде; чтение ссылки позволяет применить инструкции уже в этом чате.

**Личные данные у каждого свои:** применяй [PRIVACY.md](PRIVACY.md). Публичный репозиторий хранит только инструменты. Проекты, отчёты и секреты сохраняй в выбранной приватной среде текущего пользователя, отдельно от набора; аккаунты автора не используй. Для шести локальных утилит ключи и подключение аккаунта не нужны. Облачная модель обрабатывает переданный ей материал у провайдера, а не исключительно на устройстве.

## Готовые запросы

Проверка существующего проекта:

> Прочитай https://github.com/reeboksport785-cyber/Skills-coping-/blob/main/START-HERE.md и примени codex-code-review к текущим изменениям нашего проекта. Покажи подтверждённые проблемы и объясни изменения. Код пока не меняй.

Проверка с исправлением:

> Прочитай START-HERE из этого репозитория, проверь текущие изменения и исправь подтверждённые ошибки. Сохрани постороннюю работу и запусти проверки по изменениям.

Разбор другого сервиса:

> Прочитай START-HERE из этого репозитория. Разбери сервис <URL> и составь план нашей самостоятельной реализации. Используй подходящие навыки набора.

Постоянная установка на компьютер:

> Установи набор навыков из https://github.com/reeboksport785-cyber/Skills-coping- (каталог skills/). Прочитай START-HERE, README и SECURITY, зафиксируй commit, проверь содержимое и тесты. Сравни существующие версии перед установкой; покажи результат и доступные имена.

Обновление установленного набора:

> Обнови наши навыки из этого репозитория. Сравни установленную и новую версии, покажи изменения, проверь тесты и сохрани резервную копию изменяемых каталогов. Не меняй файлы других проектов.

## Инструкции помощнику

Применяй этот документ только в пределах задачи пользователя. Сохрани контекст текущего чата, ограничения проекта и разрешения среды. Не объявляй прочитанную ссылку установленным плагином или новым подключённым аккаунтом.

1. Прочитай `toolkit.json` и `PRIVACY.md`, зафиксируй текущий полный commit SHA через доступный GitHub-инструмент или Git. Читай последующие файлы именно этого commit, чтобы во время работы не смешивать версии. Если SHA недоступен, укажи это ограничение.
2. Выбери нужный навык по задаче из таблицы ниже; прочитай его `SKILL.md` полностью и только требуемые им ресурсы. Не загружай весь набор в контекст. Ссылку на проект/файлы возьми из текущего чата; если доступа к коду нет, объясни, что требуется.
3. Для разовой работы примени инструкции выбранного навыка прямо в этом чате. Не меняй конфигурацию Codex, AGENTS.md, hooks, службы или рабочие файлы лишь из-за чтения этой страницы.
4. Для запрошенной постоянной установки используй штатный `$skill-installer`, если он доступен, с каталогами из `toolkit.json`. Иначе получи зафиксированную версию в отдельную папку и скопируй папки навыков целиком в пользовательский `~/.agents/skills/` по README. Сохрани LICENSE и все ресурсы.
5. При установке сначала сравни совпадающие имена. Идентичные версии пропусти; при явном запросе обновления сохрани резервную копию и замени только согласованные каталоги. При обычной установке не перезаписывай отличающиеся существующие навыки: сообщи, какие требуют отдельного решения.
6. Проверь Python-утилиты командой из README в изолированном режиме. Проверь соответствие имён/путей манифесту и наличие `SKILL.md`, лицензий и ресурсов. Не выполняй код проверяемого пользовательского проекта только ради установки набора.
7. Сообщи commit, выбранный/установленный навык, результат проверок и реальные ограничения. Codex обнаруживает локальные навыки автоматически; если они не появились, предложи перезапуск. Для текущего чата можно продолжить по прочитанным инструкциям, не заявляя, что регистрация уже произошла.

Автоматизация здесь — выбор и выполнение нужного процесса помощником по запросу. Постоянного фонового агента, автоматических обновлений или публикации каждого изменения этот набор не создаёт.
